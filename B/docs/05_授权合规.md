# 5 授权与合规：一行一张，缺一项不入库

## 5.1 四个源的许可对比

| 源 | 许可 | 商用 | 署名 | 改作 | 主要风险 |
|---|---|---|---|---|---|
| Unsplash | Unsplash License | 可 | 不强制 | 可 | 不得把图片原样做成图库售卖 |
| Pexels | Pexels License | 可 | 不强制 | 可 | 含可识别人物时需另行处理 |
| Wikimedia | CC0 / CC BY / CC BY-SA | 视版本 | CC BY 系必须 | 视版本 | SA 有传染性，改作需同许可发布 |
| iNaturalist | CC0 / CC BY / CC BY-NC | NC 不可商用 | 必须 | 视版本 | NC 只能用于课程与非商业演示 |

三条落地判断：

1. **课程作业属于非商业用途**，NC 可用，但必须在文档与页面写明「仅用于课程演示，非商业」。答辩被追问时，这句话要能立刻说出来。
2. **CC BY-SA 的素材只用于展示，不做二次创作分发**。若 D 的合成图要放进公开仓库，合成图里含 SA 素材的部分需同许可发布——这条提前告知 D，别到部署前才发现。
3. **Unsplash/Pexels 虽不强制署名，仍然署**。理由不是法律，是课程评分：第 2 条要「授权表」，有作者有链接才叫表。

## 5.2 署名模板

```text
[Unsplash]  Photo by {author} on Unsplash — {page_url}（Unsplash License）
[Pexels]    Photo by {author} on Pexels — {page_url}（Pexels License）
[Wikimedia] "{file_title}" by {author}, {license}, via Wikimedia Commons — {page_url}
[iNaturalist] (c) {author}, some rights reserved ({license}) — {page_url}
```

落地位置三处：案例页每张图 hover 显示作者与许可；导出图右下角一行小字「图片来源与许可见授权表」；文档附录列授权表全表。三处都不省略，因为答辩最容易被问的就是「这张图哪来的」。

## 5.3 授权表字段

| 字段 | 必填 | 示例 | 说明 |
|---|---|---|---|
| no | 是 | 17 | 自增序号，一行一张 |
| item_id | 是 | P01 / C-023 | 关联素材或案例编号 |
| file_name | 是 | assets/cutout/P01/P01_front_inat.png | 与磁盘路径完全一致 |
| source_platform | 是 | iNaturalist | 平台名 |
| source_url | 是 | https://www.inaturalist.org/observations/414874975 | 可回源页面 |
| author | 是 | Jane Doe | 原作者署名 |
| license | 是 | CC BY-NC 4.0 | 许可全称 |
| license_url | 是 | https://creativecommons.org/licenses/by-nc/4.0/ | 许可原文链接 |
| collected_at | 是 | 2026-11-15 | 采集日期 |
| proof_path | 是 | assets/inbox/_candidates.jsonl | 采集证据（日志行） |

填写规则只有一条：**一行一张，五项核心信息（文件名、URL、作者、许可、时间）缺一项就不入库**。`collect.py` 在下载时强制写入，`qc.py` 反查该行是否存在，人没有机会漏填。

## 5.4 合规红线

- 不采需要登录或版权不清的平台（小红书、淘宝、京东、闲鱼）；
- 不用生成式模型「画」植物充当实拍素材（需求第 9 节明确排除）；
- 不裁掉、不遮挡、不伪造水印与作者信息；
- NC 素材不用于任何商业场景，包括作品集售卖与商单；
- 宜家官网图只做离线统计，不进 `assets/`、不上页面。

## 5.5 课程第 2 条的证据链

| 课程要求 | 我方证据 | 答辩怎么说 |
|---|---|---|
| 多源 | Unsplash / Pexels / Wikimedia / iNat 四个源 + 采集日志 | 同一株植物在三个源都有候选，我们按授权干净程度取舍 |
| 多模态 | 图像（素材/案例）+ 文本（百科/原则/痛点） | 5 类资产、2 种模态、4 个平台 |
| 可追溯 | 授权表逐行 + 采集 jsonl | 随便点一张图，30 秒内能找到作者与许可 |
| 过程可复现 | `collect.py` 一条命令重跑 | 不是手搓的，是脚本按同一套规则跑的 |

这一条是 B 在答辩里唯一能「一个人讲满 2 分钟」的部分，第 10 节给了逐句台词。
