## 6.5 三个接口

**给 D：素材可用性清单**（W2 周五交接，格式 JSON，字段冻结后改动提前一天通知）：

```json
{
  "schema": "verda.assets.index/1.0",
  "generated_at": "2026-11-15",
  "count": {"total": 36, "cutout_ready": 0},
  "items": [{
    "plant_id": "P01", "name_cn": "龟背竹", "has_cutout": false,
    "file": null, "width": null, "height": null,
    "height_range_cm": [80, 180], "spread_cm": 80,
    "dominant_hex": null, "light_level": "L2",
    "pet_safe": false, "toxic": "toxic",
    "style_tags": ["tropical", "minimal"], "priority": "P0"
  }]
}
```

`has_cutout=false` 的植物，前端按 FR-07 标「仅参考」并灰显，避免用户点了没反应。

**给 E：缩略图规格**。原图 ≤1600px PNG（不放大，QC 保底 1200）用于合成，列表页另出 `P01_front_inat.thumb.webp`（宽 480，质量 82，透明底）。命名规则与主图一致，只多 `.thumb` 后缀；E 不用自己裁图。

**给 C：评分要用的四个字段**。`dominant_hex`（色彩和谐）、`form` + `leaf`（形态对比）、`height_range_cm`（层次比例）、`style_tags`（风格一致）。素材只提供 `dominant_hex`，**不参与评分计算**，这是需求 FR-05 的硬约束。

## 6.6 变更规则

- 字段冻结：W2 周三与评分返回结构一起冻结（分工表第 6 节）。
- 只加不删：新增字段给默认值；废弃字段标 `deprecated` 并保留一个版本。
- 改动流程：改字段的人提前一天在群里说，同步 mock 与本文档版本号；B 负责改 `data/` 与 `schema/`，C/D 负责改消费端。
