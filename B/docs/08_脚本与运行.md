# 8 脚本与运行：五条命令、四个源、三种兜底

## 8.1 环境

Python 3.11 即可，不需要 GPU。硬依赖只有 `requests`、`pillow`、`numpy`。去底有三条路：`onnxruntime` + u2net 模型（默认 `--engine onnx`，单张 1–3 秒）、`rembg`（`--engine rembg`）、纯色泛洪（`--engine simple`，只适合白底/纯色背景）。

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r scripts/requirements.txt
# 国内网络建议加镜像
.venv\Scripts\python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple rembg[cpu]
```

## 8.2 五条命令

```bash
cd scripts
python verify_taxa.py                     # ① 学名与来源校验（一次性，写 taxa_verified.csv）
python collect.py inat --plants P01,P02 --limit 1   # ② 采集候选 + 写授权
python collect_pexels_web.py --plants P01 --limit 4  # ② 无 Key 采 Pexels（经 jina 读搜索页）
python cutout.py                          # ③ 去底 + ≤1600px + 主色
python qc.py --strict                     # ④ 质检，fail 中止
python export_index.py && python package.py         # ⑤ 导出索引 + 打包
```

## 8.3 参数速查

| 脚本 | 关键参数 | 说明 |
|---|---|---|
| collect.py | `--plants P01,P02` / `all` | 指定植物；`all` 为 36 种 |
| collect.py | `--limit N` | 每种最多入库张数，默认 1 |
| collect.py | `--min-edge 1200` | 长边下限，低于直接拒收 |
| collect.py | `--dry-run` | 只探测不落盘，用来估命中率 |
| collect_pexels_web.py | `--limit 4` | 无 Key 采 Pexels；作者与页面在定稿时回填 |
| cutout.py | `--engine rembg` / `simple` | 默认 rembg；纯色背景可用 simple |
| qc.py | `--strict` | 有 fail 返回码 1，可挂 CI |
| package.py | 无 | 生成 MANIFEST.json + sha256sums.txt + zip |

## 8.4 三种兜底

**没有 Unsplash/Pexels Key** → 跑 `collect.py inat`（iNaturalist 开放 API，无需 Key）；或跑 `collect_pexels_web.py`，它经 r.jina.ai 读 Pexels 搜索页拿 photo_id，再直连 `images.pexels.com` 下载，作者与页面在定稿时回填，授权口径不变。

**Wikimedia 访问不了**（国内网络常见）→ 跳过 `commons`，用 `inat` 顶。本包已把 iNat 列入白名单，许可为 CC0/CC BY/CC BY-NC，署名可查。

**rembg 装不上或模型下载失败** → 两种走法：纯色背景图用 `cutout.py --engine simple`；复杂背景图用 remove.bg（每月 50 张免费额度）跑完放回 `assets/cutout/Pxx/`，再手动补清单行。不要用「不处理直接放上去」蒙混——`qc.py` 会因为没有 alpha 判 fail。

## 8.5 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| `HTTP 401` | Key 未设置或失效 | 设 `UNSPLASH_ACCESS_KEY` / `PEXELS_API_KEY` 环境变量 |
| 下载卡住数十秒 | 图源 CDN 在境内慢 | 换源，或先 `--dry-run` 选快源 |
| `不是有效图片` | 拿到的是网页/占位图 | 检查 URL 是否被重定向到登录页 |
| `尺寸不足` | 原图只有 1024px | 换源；Unsplash 用 `full` 不用 `regular` |
| `去底失败` | u2net 模型未下载 | 下载到 `~/.u2net/u2net.onnx`（176MB，见 8.1） |
| `未知植物编号` | plant_id 写错 | 用 `plants_master.csv` 里的 P01–P36 |

## 8.6 时间估算（单人）

| 环节 | 数量 | 单件耗时 | 合计 |
|---|---|---|---|
| 采集候选（含授权） | 36 种 × 2 张 | 1–2 min | 1.5–2.5 h |
| 去底 + 规格化 | 72 张 | 3–5 s | 5–10 min |
| 自动质检 | 36 张 | 1 s | 1 min |
| 人工目检 + 返工 | 36 张 | 2–3 min | 1.5 h |
| 案例采集 + 打标 | 120 张 | 2 min | 4 h |
| 授权表整理 | 150 行 | — | 0.5 h |

总计约 8–9 小时，摊到 W1–W3 三周，每周 3 小时左右，与分工表给 B 的 25% 工作量吻合。
