# 17. 前端验收演示脚本（E）

> 用途：给组长/评委现场验收用。一场 8 分钟，按下面的顺序点，每一步都有"对方应该看到什么"。
> 前置：仓库根目录两条命令起服务（见第 1 节），打开带 `?api=` 的地址。

## 1 开场 30 秒：一屏看到成品

```bash
cd verda
python app.py --port 5055        # 终端 1：后端（D 的）
python -m http.server 8123       # 终端 2：仓库根目录，前端静态
```

打开 `http://127.0.0.1:8123/frontend/index.html?demo=1&api=http://127.0.0.1:5055`

**对方应该看到**：一张真实客厅照片，三株真实去底植物按 130/70/45cm 立在地面上，右下角「效果示意 · 植境 Verda」，底部综合分 87.2，右栏已有植物列表和四条搭配理由。

一句话开场：「这是照片模式，植物是按真实株高缩放、服务端合成的，不是贴图示意。」

## 2 演示路径（7 步，每步 1 分钟）

| # | 你点什么 | 对方应该看到 | 对应需求 |
|---|---|---|---|
| 1 | 「换一张照片」→ 选一张自己手机拍的房间图 | 5 项校验逐条打勾（分辨率/清晰度/亮度/过曝/地面），不合格会给出重拍建议 | FR-01 |
| 2 | 「① 画落地线」点两下 → 「② 标定高度」选「门 2.0m」点门框上下沿 | 读数变成 `2.80 px/cm`，提示行写明参照物与倾斜角 | FR-02（3 步内完成） |
| 3 | 「自己搭配」→ 点「龟背竹」+ | 植物落到地面，选中框 + 株高 130cm | FR-07 |
| 4 | 拖着这株往上抬 | 顶部浮标显示「离地 65 cm」，尺寸不变；松手后底部读数变「本地合成（含离地）」 | 摆放自由度 |
| 5 | 顶栏勾上「有宠物」 | 评分条下方**红色告警**：「家里有宠物，但含 3 株有毒植物：龟背竹、虎尾兰、绿萝」 | FR-06 硬约束，不被平均分掩盖 |
| 6 | 「AI 推荐」→「生成 3 套方案」→ 任选一张「放到照片里」 | 三套方案卡（性格/清单/价格/工时/分数），套用后照片里植物自动换成该方案并重新合成 | FR-03 + 双入口 |
| 7 | 「一句话改稿」点「对猫狗安全」 | 回显「保留 X%，总分 a → b」，可一键套用 | FR-08 |
| 8 | 「导出效果图 PNG」+「导出采购清单」 | 下载合成图（右下角带水印）+ 一份含株高/冠幅/价格/工时/评分理由的 Markdown 清单 | FR-10 |

**收尾必演**：把地址里的 `?api=...` 删掉刷新 → 页面照常能用（植物、锚定、拖拽、导出都在），只有评分/推荐位置写着「需要后端」。
一句话：「断网、没有 Key 也能演示，这是降级路径。」→ AC-10

## 4 会被问到的五个问题

**Q：这是你做的？还是后端做的？**
「界面、交互、尺度锚定的几何、拖动与摆放、导出、降级，是我做的。合成、七维评分、推荐、改稿是 D 和 C 的接口，我只负责调。所以验收时如果说'合成假'，那是 D 的合成参数和 B 的素材，不是界面。」

**Q：有些植物看着像贴图？**
「两类原因，都在 `docs/16`：① 48 张素材里 23 张是程序生成的插画（红掌、春羽、常春藤等），插画贴进真实照片必然违和；② 合成端还没做色温/亮度匹配。我已经把插画在界面里标出来了、也给了「只看实拍」筛选，所以演示不会拿插画冒充合成效果。」

**Q：能放到网上给别人看吗？**
「按你的安排部署先暂停了。方案在 `docs/15` 第 6 节：nginx 出静态 + 反代 `/api` 到 gunicorn，`assets/` 不进 Python worker。恢复后一天能上。」

**Q：案例库能搜吗？**
「能按房间/风格筛，'找相似'还没做——需要 D 补 `GET /api/cases`，前端只改一处。」

**Q：手机上能用吗？**
「需求写的是 1440 优先、≥1024 可用，这个范围我自检过。手机端没做适配，属于范围外。」

## 5 主动交代的三个缺口（先说，别被问出来）

1. **离地摆放目前是前端合成**：服务端 `/api/compose` 只有 `x`，没有 `y`。所以有植物悬空时，预览与导出走前端 canvas；全部贴地时仍走服务端。要交给服务端，需要 D 加一个 `y` 字段。
2. **素材量与质量**：23 张插画 + 3 张实拍硬伤（P18 带背景墙、P05 白底残留、P06 欠曝），已列清单给 B。
3. **合成未做色温匹配**：素材饱和度 47.5 vs 房间 23.7，`docs/16` 第 4 节给了四条改法和参数，等 D 排期。
