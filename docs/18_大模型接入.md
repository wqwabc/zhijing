# 15 大模型接入：看图选株（DeepSeek）

> 目标：让大模型根据房间照片“选哪几株、多高、放哪”，但**不生成植物图片**。
> 植物仍来自 `assets/cutout` 的实拍去底素材，合成仍走 `server/compose.py`。

## 15.1 为什么不让大模型生成图片

| 方案 | 问题 |
|---|---|
| 大模型直接出图 | 语言模型不能输出图片；图像生成要靠扩散模型 |
| 扩散模型生成新植物 | 会改叶形/盆形，不可控；需求第 9 节明确“不做生成式画植物” |
| **大模型选株 + 现有素材合成** | 可控、可解释、可回源；模型只做“搭配判断” |

所以接入的是 **DeepSeek 文本模型**，它拿到的是照片的统计特征，不是照片本身。

## 15.2 链路

```text
用户照片
  → server/room.py 提取特征（主色/亮度/暖度/绿色占比/估计风格与光照）
  → server/llm.py 拼 prompt 调 DeepSeek（只发特征 + 植物目录）
  → server/design.py 本地校验：宠物安全 / 光照 / 株高 / 素材可用 / 数量
  → verda.score_combo 确定性评分（分数永远不来自模型）
  → server/compose.py 用实拍素材合成
```

任何一步失败（没 Key、超时、JSON 不合法、选出的 plant_id 不存在），
自动退回 `verda.recommend` 的规则方案，接口结构不变（AC-10）。

## 15.3 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 空 | 不设置则走规则兜底 |
| `DEEPSEEK_BASE` | `https://api.deepseek.com` | OpenAI 兼容地址 |
| `DEEPSEEK_MODEL` | `deepseek-chat` | 模型名 |
| `DEEPSEEK_TIMEOUT` | `20` | 秒 |

```powershell
$env:DEEPSEEK_API_KEY="sk-..."
python app.py
```

## 15.4 接口

`POST /api/design`

请求：

```json
{
  "photo_id": "ph_ab12cd34",
  "scene": {
    "room": "living",
    "style": "nordic",
    "light": 2,
    "weekly_minutes": 30,
    "has_pet": true,
    "budget": 500
  },
  "count": 3,
  "anchor": {"px_per_cm": 3.2, "ground_y": 860}
}
```

`anchor` 可省略：省略时按「照片高度 50% ≈ 150cm」估一个比例，并在 `warnings` 里说明。

响应（节选）：

```json
{
  "design": {
    "source": "llm",
    "model": "deepseek-chat",
    "llm_available": true,
    "summary": "……",
    "elapsed_ms": 1834.2
  },
  "features": {"palette": [...], "brightness": 0.63, "style_guess": "nordic", "light_guess": 3.0},
  "plants": [
    {"plant_id": "P17", "name_cn": "发财树", "kind": "photo",
     "height_cm": 120, "x": 420, "layer": 0, "why": "……"}
  ],
  "score": {"aesthetic": 81.2, "fit": 90.4, "total": 84.1, "dimensions": [...]},
  "image_url": "/api/compose/so_9d2f01.png"
}
```

`design.source` 只有两个值：`llm`（模型选出且通过校验）或 `rules`（兜底）。

## 15.5 本地校验（模型说了不算）

模型返回后，`server/design.py` 会逐条过滤：

| 校验 | 处理 |
|---|---|
| `plant_id` 不在主数据 | 丢弃 |
| 素材 `available=false` | 丢弃 |
| 有宠物但 `pet_safe=false` | 丢弃 |
| 植物光照比用户光照高 2 档以上 | 丢弃 |
| `height_cm` 超出株高区间 | 夹回区间 |
| `x_frac` 越界 | 夹到 0.08–0.92 |
| 重复 id / 超过 count | 去重、截断 |

过滤后为空 → 规则兜底。

## 15.6 隐私与合规

- **照片不出本机**：只把主色、亮度、暖度、绿色占比、估计风格/光照发给模型；
- 模型不接触授权表、不接触原图；
- 合成图仍标「效果示意」，素材来源仍由授权表逐张可查。

## 15.7 测试

```bash
python -m unittest discover -s tests -p "test_design.py" -v
```

覆盖：模型正常返回、宠物安全过滤、无 Key 兜底、非法 id 兜底、JSON 解析。

## 15.8 已知限制

1. 文本模型看不到照片细节（家具、遮挡、透视），只能依据统计特征；
2. 选株质量取决于目录描述，48 种之外的植物不会出现；
3. 模型延迟 1–3 秒，接口超时 20 秒；失败即兜底，不阻塞演示。
