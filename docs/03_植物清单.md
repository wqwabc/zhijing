# 3 48 种植物：怎么选的、覆盖了什么

## 3.1 选型五原则

1. **市场可得**：能在花市与主流电商买到，价格带 15–450 元，避免「图鉴里有、买不到」的品种。
2. **风格覆盖**：6 种风格每种至少 8 种可用植物，否则 C 的风格分类与 E 的筛选会出现空档。
3. **株型覆盖**：8 种株型全部覆盖，保证「形态对比」维度有足够素材做对比，而不是 48 种全是直立大叶。
4. **毒性分层**：无毒、有毒、待核三档都要有。只有无毒植物，宠物过滤就是空跑；只有有毒植物，则没有可选方案。
5. **素材可得**：优先选 CC 图多的常见种，冷门种放 P1，避免 W2 卡在「找不到图」。

## 3.5 数据可信度与口径

- **学名**：48 种逐一经 iNaturalist 分类 API 校验，35 种回填了 Wikipedia 链接；P24 龙血树未返回链接，标 `pending`，W2 补。
- **毒性**：以 ASPCA 有毒植物库为准。未收录的 1 种（P18 幸福树）标 `unknown`，推荐时按有毒处理——**宁可少推，不可推错**。
- **株高/冠幅**：室内盆栽常见值，取区间，不含地栽极限值。合成按区间中位数缩放，留 ±15% 容差。
- **价格**：2026 年电商常见区间，随季节波动；只用于预算档位判断，不做精确报价。
- **养护工时**：按「每周分钟数」计，含浇水、擦叶、修剪，不含换盆与施肥的大块时间。

口径写在这里的意义：D 拿去做缩放、C 拿去做适配分、A 拿去做验收，三方用的是同一套数，不会各说各话。
