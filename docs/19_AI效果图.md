# 19 AI 效果图（通义万相）

> 目标：用户在画布上摆好植物后，点「✨ 生成效果图」，由图像编辑模型把植物融入房间。
> 当前状态：接口已通、可出图，但**效果还不稳定**，见 19.4。

## 19.1 链路

```text
照片 + 植物位置
  → compose 合成初稿（带接触阴影）
  → 按植物 alpha 生成 mask（外扩 + 柔化）
  → 通义万相 wanx2.1-imageedit
     function=description_edit_with_mask
  → 轮询任务 → 下载结果 → 加水印 → 返回 /api/compose/<name>
```

无 Key / 调用失败：直接返回初稿，`source=local`，前端提示“已用本地合成”。

## 19.2 配置

| 环境变量 | 说明 |
|---|---|
| `DASHSCOPE_API_KEY` | 阿里云百炼（北京地域）Key |

也可以由前端在请求头 `X-Wanx-Key` 里临时传，后端不落盘。

```powershell
$env:DASHSCOPE_API_KEY="sk-..."
python app.py --port 5057
```

## 19.3 接口

`POST /api/generate`

```json
{
  "photo_id": "ph_ab12cd34",
  "items": [{"plant_id": "P17", "x": 420, "height_cm": 150, "layer": 0}],
  "anchor": {"px_per_cm": 3.11, "ground_y": 793}
}
```

`anchor` 可省略，省略时按「照片高度 50% ≈ 150cm、落地线 85%」估算。

响应：

```json
{
  "image_url": "/api/compose/so_9d2f01.png",
  "source": "wanx",
  "elapsed_ms": 13661.5,
  "items_meta": [...],
  "warnings": []
}
```

- `source=wanx`：模型出图；
- `source=local`：未配 Key 或调用失败，返回本地合成。

## 19.4 实测（2026-11-22）

用 `nordic_living_01.jpg`，P17 发财树，x=420、150cm：

| 方式 | 耗时 | 结果 |
|---|---|---|
| `description_edit_with_mask` | 22.8s | **植物被整个抹掉**，只剩房间 |
| 按 alpha 的 mask + 明确“保留植物”提示 | 13.7s | 植物仍被替换成怪兽叶片，花盆消失 |
| `description_edit`、strength=0.35 | ~14s | 植物被抹掉 |
| `description_edit`、strength=0.2、明确“不要删除” | ~28s | 植物保住了，但叶片被改写、墙面出现漂浮色块 |

结论：**万相会把“看起来不自然”的插入物当成需要修复的对象**，而我们的初稿本身几何就不合理（植物悬在沙发前、没有真实落地），所以它倾向于重画或删除。

## 19.5 下一步

1. 先把落地关系做实：默认落地线放在 88%–90%，植物不跟沙发/床穿插；
2. mask 只覆盖“花盆底部 + 阴影带”，不覆盖整株，避免模型重画植物本体；
3. 提示词只要求“补接触阴影、匹配色温”，不要求“生成植物”；
4. 若仍不行，换即梦 SeedEdit 3.0（约 ¥0.2/张）或 Gemini 2.5 Flash Image（约 $0.039/张）。
