# 19 AI 效果图（Seedream 5.0 Flash / 通义万相）

> 目标：用户在画布上摆好植物后，点「✨ 生成效果图」，由图像模型把植物融入房间。
> 默认走**火山方舟 Seedream 5.0 Flash**；可用 `IMAGE_PROVIDER=wanx` 切回通义万相。

## 19.1 链路

```text
照片 + 植物位置
  → compose 合成初稿（带接触阴影）
  → 默认：Seedream 5.0 Flash（参考图 + 指令编辑）
     可切换：通义万相 wanx2.1-imageedit（植物 alpha mask 局部重绘）
  → 下载结果 → 加水印 → 返回 /api/compose/<name>
```

无 Key / 调用失败：直接返回初稿，`source=local`，前端提示“已用本地合成”。

## 19.2 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `ARK_API_KEY` | 空 | 火山方舟 API Key（Seedream 用） |
| `ARK_IMAGE_MODEL` | `doubao-seedream-5-0-flash-260915` | 模型 ID，以控制台为准 |
| `IMAGE_PROVIDER` | `seedream` | `seedream` 或 `wanx` |
| `DASHSCOPE_API_KEY` | 空 | 切到万相时才需要 |

```powershell
$env:ARK_API_KEY="..."
$env:ARK_IMAGE_MODEL="doubao-seedream-5-0-flash-260915"
python app.py --port 5057
```

前端 ⚙ 设置里也可以填「图像 Key（火山方舟）」，只存 `sessionStorage`，
请求时通过 `X-Ark-Key` 传给后端；`X-Wanx-Key` 对应万相。

## 19.3 接口

`POST /api/generate`（字段不变）

```json
{
  "photo_id": "ph_ab12cd34",
  "items": [{"plant_id": "P17", "x": 420, "height_cm": 150, "layer": 0}],
  "anchor": {"px_per_cm": 3.11, "ground_y": 793}
}
```

响应：

```json
{
  "image_url": "/api/compose/so_9d2f01.png",
  "source": "seedream",
  "elapsed_ms": 8123.4,
  "items_meta": [...],
  "warnings": []
}
```

`source`：`seedream` / `wanx` / `local`。

## 19.4 Seedream 5.0 Flash 调用

```text
POST https://ark.cn-beijing.volces.com/api/v3/images/generations
Authorization: Bearer $ARK_API_KEY

{
  "model": "doubao-seedream-5-0-flash-260915",
  "prompt": "以这张室内照片为基础，把画面中的绿植自然地融入环境……",
  "image": ["data:image/png;base64,..."],
  "size": "2K",
  "response_format": "url",
  "watermark": false
}
```

- `image` 传合成初稿（含植物）；
- 不用 mask，靠指令要求“保留房间、家具、植物位置”；
- 返回 `data[0].url`，后端下载后加水印。

## 19.5 实测（2026-11-22，通义万相）

用 `nordic_living_01.jpg`，P17 发财树，x=420、150cm：

| 方式 | 耗时 | 结果 |
|---|---|---|
| `description_edit_with_mask` | 22.8s | 植物被整个抹掉 |
| alpha mask + 明确“保留植物” | 13.7s | 植物被替换，花盆消失 |
| `description_edit`、strength=0.35 | ~14s | 植物被抹掉 |
| `description_edit`、strength=0.2 | ~28s | 植物保住但变形、墙面色块 |

结论：万相会把“看起来不自然”的插入物当成需要修复的对象，效果不稳定，所以换 Seedream。

Seedream 5.0 Flash 的实测待补（需要 `ARK_API_KEY`）。
