# 16. 素材与合成质量问题清单（"像贴图"专项）

> 提出：E ｜ 2026-11-22 ｜ 涉及：B（素材）、D（合成）、A（验收口径）
> 起因：自选/推荐里部分植物放进照片后明显像贴图。逐张看过之后，原因是三层，不是一个问题。

## 1 结论先说

| 层 | 问题 | 影响面 | 谁修 |
|---|---|---|---|
| 素材类型 | **48 张素材里 23 张是程序生成的插画**（`assets/illustrations/`），不是实拍去底 | 48% | B 补实拍 |
| 素材质量 | 3 张实拍素材有硬伤：掩膜把背景一起留下 / 严重欠曝 | 3 张 | B 重做 |

一句话：**一半是"图不对"，一半是"贴得不对"**。前端已经先把"图不对"这部分标出来了，避免演示时被评委指着问。

插画是 FR-05 的既定回退策略（缺图回退插画，不开天窗），本身不算 bug；但**插画是纯色平涂 + 无光影，贴进真实照片必然违和**，这是"太假"最主要、也最好解释的来源。答辩时如果被问，正确口径是"这 23 种是形态示意图，实拍在补"，而不是装作是合成效果。

## 3 素材质量：3 张实拍有硬伤

| 素材 | 现象 | 证据 |
|---|---|---|
| **P18 幸福树** | 掩膜把植株后面的**整面灰墙**一起抠了下来，贴进任何房间都带着"另一间屋子"的底 | `docs/figs/P18-mask-residue.jpg` |
| **P05 绿萝** | 叶片之间的空隙保留了**白色背景**（不是透明），贴到深色家具前是一块白楔子 | `docs/figs/P05-alpha-residue.png` |
| **P06 白掌** | 严重欠曝，叶片接近纯黑剪影，只剩花盆是亮的 | 直接看 `assets/cutout/P06/P06_front_pexels.png` |

这三张的共性是 `qc.py` 现有 9 项指标抓不到：它测的是 alpha 覆盖率/边缘/长边，但**不测"掩膜内部是否有背景色残留"**，也不测整体曝光。建议 B 在 `qc.py` 加两项：

```python
# 掩膜内"背景色"占比：低饱和 + 高亮(白底) 或 低饱和 + 中亮(灰墙)
# 阈值参考：>10% 判 fail，>5% 报警
# 整体亮度：剪影化判据 —— 掩膜内 lum 均值 < 40 且 p90 < 90 → fail
```

## 4 合成：没有环境适配

实测（同一批素材与同一张房间图）：

| 指标 | 素材平均 | 房间 | 差距 |
|---|---|---|---|
| 饱和度（HSV S 均值） | 47.5 | 23.7 | 素材艳 **2 倍** |
| 亮度（RGB 均值） | 55.4 | 167.9 | 室内的墙是亮的，叶是暗的（合理），但没有做方向性匹配 |

`server/compose.py` 目前只做「等比缩放 + 贴地 + 椭圆阴影 + 水印」，文件头也自己写了「W2 再做：色温匹配」。四件事按性价比排序：

1. **饱和度/亮度匹配**（最有效）：按房间图统计，把植物层降到 `sat × 0.65~0.75`，亮度按 `room_mean × 0.7` 做增益，再叠一点点暖色（`R×1.03, B×0.97`）。见 `docs/figs/compose-tone-before-after.png`，左边是现状，右边是只做了这一步的对比。
2. **边缘收紧 1px**：`alpha = MinFilter(3)` 去掉白边/浅色描边。对 P05 这种白底残留尤其明显。
3. **接触阴影加强**：现在椭圆阴影 alpha 太淡、几乎看不见（放大看盆底是硬切边）。建议 alpha 0.30~0.40、宽度按盆宽 1.1~1.2 倍、模糊半径 `max(3, 0.07×盆宽)`。
4. **（可选）远处降对比**：y 越靠上（越远）轻微降饱和 + 降锐度，制造空气透视。
